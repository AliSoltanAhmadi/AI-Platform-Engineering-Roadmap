# Beginner First Task — AI Platform Engineering Basics

## What is AI Platform Engineering?
A practical career upgrade path for DevOps / Platform / SRE engineers moving into ML and LLM platforms.

## Key Areas
- **MLOps**: pipelines, registries, model drift, experiment tracking
- **LLMOps**: vLLM, RAG, GPU scheduling, model gateways
- **Tools**: Docker/Kubernetes, CI/CD, observability

## Your Path (RoadMap/ai_platform_roadmap.md)
- P0 Foundations (Linux, containers)
- P1 Core Concepts (ML lifecycle)
- P2 Pipelines (training / inference)
- P3 Deployment (K8s / serving)
- P4 LLMOps (vLLM, RAG, GPU scheduling)
- P5 Portfolio (end-to-end project)

## First Challenge
Pull the `nginx` container image to begin practice.
Enter only the command you would run. Think about the runtime, the operation, and the requested image.
