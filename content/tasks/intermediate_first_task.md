# Intermediate Lesson — Reproducible ML Data

MLOps makes ML work reproducible by versioning code, data, and model artifacts. A typical first workflow loads a dataset with Python, tracks it with DVC, and then runs repeatable steps in an orchestrated environment.

An artifact registry gives the team a versioned place for model or container artifacts. Inference is the later step where a trained model receives input and produces output.

Prerequisites: Python basics and container fundamentals.
